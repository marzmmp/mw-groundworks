## What this is

A website for **M&W GroundWorks**, a land and property services company in
Jefferson County, Missouri. Seven pages, already built and tested. I want to
keep developing it with you so I can see it as we go.

## The one thing that makes this site unusual

The hero is a live 3D scene: the extruded M&W mark standing in an animated,
wind-blown grass field, and **the whole scene follows the real position of the
sun over Jefferson County**. Night → sunrise → morning → midday → golden hour →
dusk, continuously, and it shifts with the seasons on its own because it runs an
actual solar-position calculation rather than mapping clock hours to presets.

Please don't simplify this away. It's the centrepiece.

## Ground rules

1. **Don't hand-edit the HTML.** All seven pages are generated by
   `tools/build_site.py` from `tools/content.py`. Edit those and re-run
   `python3 tools/build_site.py`. Hand-editing HTML gets silently overwritten.
2. **Don't hand-edit `website/assets/js/grass.js`.** It's generated by
   `tools/make_grass_module.py`, which lifts the GLSL verbatim from the original
   shader source. Edit the generator.
3. **Zero third-party runtime requests.** Fonts and Three.js are self-hosted on
   purpose — no Google Fonts, no CDN, no tracking. Please keep it that way.
4. **Nothing unverifiable goes on the page.** See the compliance section in
   `DESIGN-NOTES.md`. This is a real business and Missouri licensing rules make
   several common contractor claims misleading. Placeholders stay placeholders
   until the owner confirms them.
5. **Re-run the three test scripts after any hero change** (see below). One of
   them exists specifically because the day-cycle idea can quietly destroy text
   legibility.

## Serving it

The site needs a web server — browsers block ES modules and web fonts on
`file://`. From inside `website/`:

```
python3 -m http.server 8000
```

`single-file/index.html` is a self-contained copy that opens with no server, for
quick looks only. It's bloated on purpose; don't treat it as the source.

## Tests

```
node tools/audit.js           # contrast, overflow, links, headings, tap targets
node tools/interact.js        # 36 functional tests
node tools/daylight_check.js  # text legibility at 17 hours across the day
```

All three currently pass. They need `playwright` and `pngjs`, and the site
served on port 8787.
